# 意图规则（唯一长期资产）

> 由 `log.tsv` 蒸馏而来。每条 = `信号 → 判定 → 动作`，括号里是证据日期。
> 被推翻就直接改这一行，不要新增例外。上限 80 行，超了合并同类项。
> 累计观测：4 轮（2026-10-19 起）

## 默认值

- **拿不准 → ADVICE（只给判断）**。判成"只给意见"的代价是多一轮；判成"直接开干"的代价是白干一整轮 + 惹烦他。（2026-10-19 ×2）

## 命令 EXEC

- `现在 / 马上 / 直接` + `建 / 改 / 做 / 装 / 删 / 跑` → EXEC，立刻动手。（2026-10-19 "我建议你现在就根据这个新建一个skill"）
- 动作动词 + **具体对象**（"改第38行""删这个文件"）→ EXEC，做完 3 行内报结果。

## 征询 ADVICE

- `帮我想 / 你觉得 / 怎么样 / 行不行 / 有没有必要 / 我建议` → ADVICE，只给判断和理由，**一个文件都不碰**。（2026-10-19 "帮我想办法" 判成 EXEC → 白干一整轮）
- **问号结尾** → 默认 ADVICE。"能不能 / 要不要" 在中文里几乎都是求意见，不是授权。
- 征询结尾**不要**加"要不要我……"，给完判断就停。

## 评价 FEEDBACK

- `不是这个意思 / 你理解错了 / 你个猪` → **方向错**：换方案，不在细节上修饰。（2026-10-19）
- `还是错的 / 第X行报错` → **局部错**：只改那一处，别重写。
- `太多了 / 太麻烦 / 太长了` → 砍到只剩结论。

## 情绪 EMOTION

- 脏字开头 → 先认错**一句**（说清错在哪一步），再看后半句属于哪类。不辩解、不写分析、不道歉三百字。（2026-10-19）

## 其它

- 单字 `ok / 可以 / 嗯 / 好` → 对上一轮的确认，**不是新任务**。
- 他话越短、越口语、越带脏字 → 越是在讲**方向**，不是在挑细节。
